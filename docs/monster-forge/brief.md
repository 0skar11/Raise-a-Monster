# Monster Forge shop

Approved on 2026-10-23: the user requested full shop implementation while preserving the features of `approved-shop.png`. This is a Roblox native shop, not a website.

The approved composition has a carved midnight stone shell with bronze edges, warm ivory lettering, left category navigation, a weapon grid, and a large selected weapon with stats and purchase control on the right. The Gamepasses category has two featured offers, x2 Damage and VIP, above four smaller permanent upgrades. Art is decoration; labels, prices and controls remain native GUI objects. Weapons use the actual game models.

Preserve all current weapons, accessories, passes, products, owned and equipped states, currency distinctions, prices from Config and Marketplace, server authority, existing purchase prompts, and adult-growth selection. Extra catalog items may scroll without changing the desktop topology. Compact landscape devices use native scrolling while keeping category navigation and actions usable.

The approved mock's scene background and board captions are presentation context. Its weapon illustrations are style references; actual owned weapon models are the content authority. Purchases are not tested by spending Robux. Build, Studio runtime checks, source delivery and public publishing are separate outcomes.
