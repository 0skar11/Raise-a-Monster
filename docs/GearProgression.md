# Gear progression

Player equipment uses coins. The free starting Bat remains available.
Prices follow early / middle / late monster growth and zone progression; they are not player-level locks (there is no player-level system).

| Weapon | Coins |
| --- | ---: |
| Iron Bat | 300 |
| Iron Sword | 800 |
| Forest Sword | 2,500 |
| Desert Sword | 7,500 |
| Ice Sword | 20,000 |
| VIP Sword | 40,000 |
| Lava Sword | 80,000 |

| Accessory | Coins | Speed | Extra HP |
| --- | ---: | ---: | ---: |
| Swift Sneakers | 500 | 5% | 15 |
| Flame Boots | 1,500 | 8% | 30 |
| Ice Skates | 3,500 | 10% | 50 |
| Wind Scarf | 7,000 | 12% | 75 |
| Lightning Boots | 14,000 | 15% | 100 |
| Shadow Cloak | 28,000 | 18% | 140 |
| Void Hoverboard | 55,000 | 22% | 190 |
| Golden Wings | 100,000 | 30% | 250 |

The highest owned speed and HP bonuses apply automatically; accessories do not stack.
Base health is 100. Respawn and avatar appearance changes reapply the bonus on the server.
Upgrades preserve the current health percentage and cannot revive a dead character.
These prices are an initial balance pass and need player economy feedback.

The gear shop sits at (20, 0, -205), on the left side of the entrance against the plaza boundary, opposite the arena at positive Z.
Shop teleport arrives at (20, 4, -189), faces the counter horizontally, and clears the roof and counter.
Change `Config.Shop.Position` and `Config.Shop.TeleportOffset` together if the map layout changes.
