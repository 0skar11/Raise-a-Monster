# Colorful Monster Forge and Rewards

User approved `approved-shop-concept.png` on 2026-10-26 and explicitly requested the same visual language for Rewards, including its wheel. This replaces the gloomy shop/rewards presentation while preserving catalog, economy, ownership, server purchase prompts, selected spin results, cooldowns and daily rewards.

## Direction contract

- Cheerful cartoon world: cyan sky and cloud decoration, cream content surfaces, navy text, sunny gold headings, turquoise selection, lime enabled purchase/claim buttons, coral close controls.
- Actual interactive Roblox UI with native text and responsive layouts. Product models remain actual game models. Decorative illustrations never contain actionable labels or prices.
- The shop preserves five categories, real catalog cards and selected-item details. Rewards preserves the real prize wheel and daily rewards; countdown and disabled states remain legible.
- All replacement icons come from one authored illustration atlas. No emoji or primitive Frame-built icon substitutes.
- Clouds and illustration are raster assets; controls, wheel rotation, text, focus and state remain semantic native GUI elements.
- Desktop and compact landscape phone are required review sizes. Inspect in Studio, checking image loading and each category/Rewards state. Distinguish visual previews from actual paid purchases and public publication.

## Approval evidence

The user selected "خليه كرتوني ومليان ألوان", then approved the rendered concept and asked to apply it to Rewards as well: "مناسبه جدا اعملها لدي كمان وابدأ اشتغل".

The concept's bottom icon row is an asset showcase, not another navigation row. Illustrated title lettering is translated to a native readable heading. Item prices and effects always come from current Config/state rather than the image.
